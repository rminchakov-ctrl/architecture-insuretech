# Настройка
Конфигурация ограничивает клиентов 10 запросами в минуту, возвращая ошибку 429 при превышении этого лимита:

- limit_req_zone - создает зону для хранения состояния ограничения запросов
- - $binary_remote_addr - использует IP-адрес клиента как ключ для ограничения
- - zone=mylimit:10m - создает зону "mylimit" размером 10 МБ
- - rate=10r/m - устанавливает лимит 10 запросов в минуту
- limit_req - применяет ограничение к location
- - zone=mylimit - применяет созданную зону
- - burst=5 - позволяет обработать до 5 запросов сверх лимита с задержкой
- - nodelay - немедленно возвращает ошибку 429 при превышении лимита + burst
- limit_req_status 429 - явно устанавливает код возврата 429 при превышении лимита
